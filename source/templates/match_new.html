Analyse automatique des vidéos YouTube publiques

Si le moteur vidéo est connecté au serveur, AquaMetric peut analyser une vidéo YouTube publique directement à partir de son lien, minute par minute, sans téléchargement ni partage d'écran. Les détections alimentent progressivement le rapport, avec des contrôles de qualité. Si le lien n'est pas accessible au moteur, la capture d'onglet reste une solution de secours.

Renseigner la durée lance automatiquement l'analyse directe si le moteur est configuré. Sinon, tu pourras l'indiquer dans le dossier du match. La durée n'est pas une garantie de couverture ou de résultats sportifs.

En mode Auto, AquaMetric utilise le bandeau/scoreboard et les noms d’équipes comme ancrage. Si plusieurs rencontres restent plausibles, l’interface doit demander laquelle analyser au lieu de mélanger les matchs.

Fichier volumineux — stockage cloud optionnel

Jusqu'à 5 Go via un stockage cloud privé. Le fichier est envoyé directement par morceaux de 16 Mo : pas de requête de 3 Go vers AquaMetric, reprise possible si la connexion coupe.

Vérification du stockage vidéo disponible…

Le stockage cloud et l'analyse vidéo sont deux étapes distinctes : une vidéo reçue n'est pas considérée comme analysée. L'import cloud doit être configuré par l'administrateur. Un stockage Render gratuit ne suffit pas à conserver de gros fichiers.
Le stockage de plusieurs Go n'est pas disponible sur ce serveur.
