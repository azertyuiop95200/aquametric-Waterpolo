# Lineup performance
New candidate-only reducer joins canonical event keys with an evidenced period and actual-play clock to the unique complete lineup at a strictly interior clock value. Boundary events, contradictory player identity, missing clock evidence and replays are excluded. Both teams must be observed to assign a goal differential. Numerators are detected events, denominators are observed game-clock seconds, not full match rates. No event detected is not a sporting zero; ratios without detected numerators are withheld. Goal difference is partial, not official plus/minus. Counts by simultaneous numerical state include goalkeepers; goal/shot ratio is a detected-shot ratio, not a possession conversion measure. Clock quantization, source continuity, completeness of events and identity remain limitations. No real-match recalculation or external processing in this iteration. Legacy runs require new event evidence. Next: independent full-match event annotations, possession intervals with explicit endpoints, and calibration of coverage and error.
