# Mandat opérationnel — rapport final d'abord (28/11/2026)
Ce mandat actualise les priorités de CONVERGENCE.md et ROADMAP.md, sans supprimer leurs historiques. Objectif utilisateur : importer un match ou une URL autorisée, lancer une analyse, obtenir un rapport sportif organisé et aussi complet que les preuves le permettent. Pas de classement/scouting/score composite. Les moteurs existants sont réutilisés ; priorité absolue à leur alimentation et restitution, pas aux nouveaux indicateurs isolés.

L'intégrateur tient le registre de livraison consolidé à partir des handoffs.

## Cycle de livraison
1. Lire ce mandat, l'état GitHub/Render et les derniers journaux ; choisir un blocage réellement ouvert de sa responsabilité, réserver un périmètre de fichiers.
2. Corriger le code ou les données avec test reproductible ; mesurer avant/après, enregistrer une PR ciblée et les résultats effectivement exécutés.
3. Générer rapport réel partiel avec le générateur du site lorsque source accessible, comparer valeurs et preuves à une référence indépendante. Si inaccessible, dire exactement pourquoi et utiliser une fixture explicitement synthétique séparée.
4. Handoff : rôle, lot, SHA de base et head, PR, fichiers, entrée/version, clés snapshot, preuves des tests, couverture/erreurs, rapport privé vérifié, blocage et prochain consommateur. Pas de vidéo/annotation/identité privée, secret ou URL signée dans GitHub public. Transférer seulement via espace Drive privé autorisé, vérifier relecture.
5. Intégrateur seul : vérifier CI sur SHA courant, tests non vides et vides, QA, conflits, sauvegarde/restauration si risque, puis fusion et déploiement progressif autorisé Render My Workspace sur service Ultimate uniquement. Vérifier SHA live et rapport/export, pas de double déclenchement. Ne pas toucher main, autres services, accès, coûts ni données réelles sans autorisation. Pas de contourner protections YouTube.
Critère de clôture d'une famille : code + exécution réelle + mesure justifiée + persistance + restitution + export contrôlé. Critère de clôture du projet : rapport de match complet validé indépendamment, couverture mesurée, limites explicites, site utilisable. Ne pas déclarer un résultat sportif sur la base de tests synthétiques seuls.
