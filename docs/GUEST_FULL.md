# Extended guest Ultimate
Set AQUAMETRIC_GUEST_ULTIMATE=1 and AQUAMETRIC_GUEST_FULL=1. Guest matches have no fixed count by default (AQUAMETRIC_GUEST_MATCH_LIMIT=0); local uploads default to 250 MiB and are bounded by MAX_UPLOAD_MB. One local file analysis runs per process, with 120 visual and 40 OCR samples. Guest YouTube capture uses the browser studio; provisional candidates are distinct from confirmed events. Paid remote inference remains disabled for anonymous sessions. Cloud upload requires private object storage and durable metadata; guest limits 1 GiB per file and 2 GiB per owner. Session ownership remains unchanged. Free Render local storage can disappear; export reports. No migration of existing data is performed.
