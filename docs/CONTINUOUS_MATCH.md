# Continuous match audit
Experimental baseline, all decoded images in order, colour/optical flow proposals, no claim of sports accuracy. Local upload default mode continuous; AQUAMETRIC_ANALYSIS_MODE=sparse disables it. Temporary private frame trace for app runs, retained CLI trace via --out. OCR and existing local metric windows are separate diagnostics. Unavailable identities, calibration, ball control and event truth remain unmeasured. YouTube browser capture is not covered by this implementation. Constant frame rate input expected. Long matches require a durable worker and tested CPU/memory budget; no deployment assumed.
